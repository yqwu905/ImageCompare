# ImageComparator

## 项目描述
ImageComparator 是一个专为 Windows 平台设计的图像浏览、对比和评测软件。它旨在提供极佳的高性能体验，确保在加载和切换图片时能够保持极致的流畅度。同时，该软件拥有美观且现代化的用户界面，能够极大地提升用户的图像对比与评测体验。

## 核心要求
- **高性能与流畅性**：极致的图片加载与切换速度，无卡顿。
- **现代化 UI**：界面美观、现代化，提供极佳的用户交互和视觉体验。
- **自动化 CI/CD**：通过 GitHub Actions 实现自动化格式校验、静态检查、编译和 Windows 平台可执行程序的打包与发布。
- **技术栈**：使用 C++ 语言开发，基于最新的 Qt 6 框架实现。

## 主要功能点
- **多文件夹支持**：支持添加多个图片文件夹进行并行的图像比较。
- **智能匹配机制**：支持多个文件夹内的图片按照顺序匹配，以及按照文件名进行精准匹配。
- **定制化标注**：支持在比较界面中的每张图片上添加直观的标注，清晰表明当前比较的图片批次来源与相关信息。
- **多格式支持**：广泛支持常见的图像格式，包括 JPG, PNG, WEBP 和 TIFF。
